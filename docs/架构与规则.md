# 架构与规则

SwiftUI/AppKit 提供界面与菜单栏，CCGuardCore 保存纯规则、流程和历史解析，应用层适配系统状态、辅助功能、Chrome 调试协议和网络请求。

启动时四步串行，完整网页检查绑定本轮新导航。评分严格大于90，住宅、支持地区和风险项仅启动检查。国内出口允许智能分流；Claude/Cloudflare 出口匹配配置的 IPv4。

运行中本地约每秒检查，后台外部探测约30秒一次，不重叠、不刷新或导航检测网页，不查询评分或风险接口。原生请求使用传给 Claude Code 的代理环境；DNS/WebRTC 在专用 Chrome 隔离上下文重新主动探测。

明确异常立即撤销。暂时无结果每次失败后等待10秒重试，首次未确认起最多120秒；部分结果和反复重试不能延长期限，完整关键检查通过才恢复。停滞任务有额外失联上限。本地权限、VPN、接口变化、唤醒和独立守护的明确失效仍撤销许可。

独立守护以会话随机标识和单调时钟心跳核验主程序；退出操作按当前用户、进程号和启动时间验证身份，并覆盖关联子进程。窗口关闭和隐藏浮窗不解除守护。

数据和权限边界见仓库根目录的隐私说明，使用限制见 README。此文描述实现，不保证外部服务的正确性和可用性。
