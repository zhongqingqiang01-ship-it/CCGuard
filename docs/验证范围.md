# Verification scope

The public export is based on version 0.3.1. It uses a separate bundle identifier and local support directory. No private machine's raw acceptance records, runtime logs or screenshots are included.

Default verification covers Swift policy/workflow behavior, startup-page parsing, background probe scripts, public-export checks and an arm64 App build. Watchdog integration uses owned disposable fixture processes; it does not target real VS Code. CI does not grant Accessibility permission, sign into accounts or run a real browser/network acceptance flow.

Offline checks and successful compilation do not prove that a user's current VPN, application versions, permissions, third-party endpoints or actual Claude traffic are valid. Recipient-machine GUI and end-to-end behavior require separate local validation. Builds are ad-hoc signed, not Developer ID signed or Apple-notarized.
