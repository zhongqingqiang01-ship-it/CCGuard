# Contributing

Run `zsh scripts/check.sh`, `python3 scripts/audit-public.py`, and `zsh scripts/build.sh` before submitting a change. Use Node.js 22+ and Swift 6+. The default tests are offline and do not operate real VS Code.

Keep reputation checks startup-only, domestic split routing allowed, runtime probes free of page refresh, and stale/partial observations unable to renew permission. Do not replace unavailable observations with success. Preserve process identity and descendant checks.

Use documentation IP ranges for fixtures. Do not add local configurations, credentials, browsing captures, screenshots with personal details, real logs, certificates or compiled App bundles to commits. Review filenames, metadata and commit email as well as text. A pattern scan is an additional check, not proof that all secrets or vulnerabilities are absent.

Describe the user-visible behavior and meaningful verification in pull requests. Real VS Code start/termination acceptance must be explicitly authorized and performed after work is saved.
